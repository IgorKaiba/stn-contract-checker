# DECISIONS

| Решение | Альтернатива | Компромисс |
|---|---|---|
| Правила на ключевых словах — основной движок | LLM-извлечение | Детерминированно и проверяемо; хрупко к нетиповым формулировкам → «нет данных» |
| FastAPI + Jinja2 серверный HTML | Streamlit | Нативные якоря `#p-N` и подсветка, TestClient; чуть больше шаблонного кода |
| Цитата = предложение, срез по смещениям | Фраза-значение | Всегда совпадает с источником (V1); длиннее, чем минимально нужно |
| Абзац = блок через пустую строку | Пункт договора | Просто и стабильно; ссылка ведёт на блок из 1–2 пунктов, цитата подсвечена |
| Статус по строке «Статус:», конфликт маркеров → UNKNOWN | Эвристики по тексту | Консервативно: сомнение → «требует проверки» |
| Предложения извлекаются из проектов/писем теми же правилами | Ручной ввод | Единый код; формулировки «предлагаем …» выделены отдельно |
| LLM-слой выключен по умолчанию, принимается только при точной цитате, всегда NEEDS_REVIEW | LLM как основной путь | Не зависит от платных аккаунтов; модель не может «придумать» значение |
| Пресеты дат вопросов — в config (env) | Литералы в коде | Не путать параметры вопроса с ответами |
| Неустойка не реализована | Сделать заранее | Задача встречи; реестр готов к добавлению поля |
