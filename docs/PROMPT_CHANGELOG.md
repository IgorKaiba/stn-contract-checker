## Предложения к v1.1 (по итогам первого прогона)
- Gate ловит только перечисленные литералы; пресет даты вопроса 4 он пропустил (VIBE_LOG #3). Добавить в gate общий
  шаблон дат `\d{4}-\d{2}-\d{2}|\d{2}\.\d{2}\.\d{4}` с исключением `app/config.py`.
- В `%%DOMAIN_RULES%%/extract.amount` добавить синонимы «цена договора» (найдено в S8).
- Явно учитывать дату подписания из строки «Статус:» (уже реализовано: подписание позже даты проверки → предложение).

## Реализовано в коде при подготовке к публикации
- Gate переписан на Python (`scripts/gate.py`), кроссплатформенный; добавлен общий шаблон дат с исключением `config.py`; gate запускается как тест `tests/test_gate.py`. В промпте v1.1 заменить `%%ANTI_HARDCODE_GATE%%.impl` на `python scripts/gate.py`.
